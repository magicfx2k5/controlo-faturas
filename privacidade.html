Política de privacidade

Controlo Faturas · última atualização: 24 de novembro de 2026

A quem se aplica

O Controlo Faturas é uma aplicação de uso pessoal. É utilizada apenas pelo seu autor, com a sua própria conta Google, e não é oferecida a terceiros.

Que dados são acedidos

Com a autorização do utilizador, a aplicação usa a Gmail API com a permissão gmail.readonly (só leitura) para:

  • pesquisar mensagens com anexos PDF de faturas;
  • ler o remetente, o assunto e a data dessas mensagens;
  • descarregar os anexos PDF.

A aplicação não envia, altera nem apaga e-mails, e não acede a contactos, calendário ou outros serviços Google.

Onde ficam os dados

Os PDF e o índice das faturas ficam guardados exclusivamente no computador e no armazenamento na nuvem do próprio utilizador. Não existe nenhum servidor da aplicação que receba ou guarde estes dados.

Partilha

Os dados não são vendidos, partilhados nem transferidos para terceiros, nem usados para publicidade ou para treinar modelos de inteligência artificial.

Utilização dos dados das APIs Google

O uso e a transferência de informações recebidas das APIs Google cumprem a Política de dados do utilizador dos serviços de API Google, incluindo os requisitos de utilização limitada.

Revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. Os ficheiros já descarregados podem ser apagados diretamente das pastas do utilizador.
